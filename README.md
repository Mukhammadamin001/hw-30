# Склад — таблица из макета WEPRO

Домашнее задание: таблица склада из админки WEPRO, свёрстанная семантическими тегами.

Открыть `index.html` в браузере.

- `index.html` — разметка: таблица `table / thead / tbody / tr / th / td`, две группы позиций
  (строка-заголовок с `colspan="8"`), плюс бонус: боковое меню, карточки, фильтры, пагинация.
- `style.css` — стили: `border-collapse: collapse`, отступы в ячейках, числа выровнены вправо,
  приглушённые заголовки в `uppercase`, чередование строк, подсветка при наведении,
  бейджи статуса трёх цветов (`badge--danger`, `badge--warn`, `badge--ok`).
